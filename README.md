# TicTacToe

A console-based Tic-Tac-Toe game built with C# and .NET 10.

## Features

- Two-player gameplay
- Interactive console interface
- Input validation
- Win and draw detection
- Prevention of moves in occupied cells

## How to Run

1. Install the .NET 10 SDK.
2. Clone this repository.
3. Navigate to the project directory.
4. Run the game:

   ```bash
   dotnet run
